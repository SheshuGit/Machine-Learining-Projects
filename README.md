🧠 Machine Learning Projects Repository
This repository contains a variety of machine learning projects, implemented using Python (primarily in Jupyter Notebooks). The projects span supervised and unsupervised learning, classification, regression, clustering, dimensionality reduction, and natural language processing.

📁 Datasets
Iris.csv: Classic Iris flower dataset used for classification.

Study_vs_Score_data.csv: Dataset representing hours studied vs score – used for simple linear regression.

mail_data.csv: Used for spam vs ham email classification.

personality_dataset.csv: Dataset for personality prediction.

📘 Notebooks
📌 Classification Projects
LAB_1(Spam&ham).ipynb

Basic binary classification task (spam vs ham).

Implements text preprocessing and classifier evaluation.

LogisticRegression_Spam_Ham.ipynb

Logistic Regression model for spam/ham email classification.

Uses mail_data.csv.

Navie_Bayes.ipynb

Applies the Naive Bayes algorithm to classify textual data.

Likely used for email spam filtering.

P(Iris_NB).ipynb

Naive Bayes classification on the Iris dataset.

SVM.ipynb

Support Vector Machine classification on a general dataset (likely Iris or similar).

SVM_ImageClassification.ipynb

SVM applied to image data.

Likely includes feature extraction and image preprocessing.

📌 Regression Projects
LinearRegression.ipynb

Simple linear regression.

Uses Study_vs_Score_data.csv to predict student performance based on hours studied.

LogisctR_N.ipynb

Likely Logistic Regression for binary classification tasks.

📌 Clustering Projects
KMeans.ipynb

K-Means clustering on Iris or another dataset.

Unsupervised learning for pattern recognition.

📌 Dimensionality Reduction
PCA.ipynb

Principal Component Analysis for reducing dataset dimensions.

Includes visualization of transformed data.

📌 K-Nearest Neighbors
KNN.ipynb

Implements KNN for classification.

Likely applied to Iris or personality dataset.
